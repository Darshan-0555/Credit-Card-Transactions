# Credit-Card-Transactions
SQL-based credit card transaction analysis using PostgreSQL to explore customer spending, fraud, credit limits, transaction trends, and demographic patterns.
# Credit Card Transactions Analysis

## Overview

SQL project analyzing credit card customers, transactions, card types, credit limits, and fraudulent transactions.

## Analysis

* Customer spending patterns
* Fraud transaction analysis
* Credit limits by card type
* Transaction trends by month
* Customer and age-group analysis
* Non-transaction customers

## SQL Concepts Used

JOIN, LEFT JOIN, GROUP BY, HAVING, COUNT, SUM, AVG, MIN, MAX, CASE, subqueries, and date functions.
